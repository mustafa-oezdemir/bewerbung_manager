# AGENTS.md

## Workspace Purpose

This workspace is a German-language application-writing workspace, not a software project.

- [lebenslauf.md](d:/bewerbung/lebenslauf.md) is reference material for CV structure, ATS-friendly formatting, and common sections.
- [todo.md](d:/bewerbung/todo.md) is reference material for cover-letter structure and content.

## How To Work Here

- Default to German unless the user explicitly asks for another language.
- Treat the existing Markdown files as source notes and reference guides, not as final personalized application documents.
- When drafting application content, write original text tailored to the target role instead of reusing long passages from the reference files.
- Preserve Markdown structure with clear headings, short paragraphs, and lists only when they improve readability.

## Content Conventions

- Keep CV guidance ATS-friendly: simple structure, standard section names, and no decorative-only formatting.
- Prefer German business conventions such as DIN 5008-compatible structure, antichronological timelines, and precise dates.
- Make claims concrete and specific; prefer measurable results over generic adjectives.
- Keep cover letters to one page unless the user explicitly asks otherwise.

## Editing Boundaries

- There is no build, test, or dependency workflow in this workspace.
- Do not assume code, scripts, or automation are present.
- If the user asks for personalized application output, create or edit target documents intentionally rather than overwriting reference material by default.

## Useful Starting Points

- Use [lebenslauf.md](d:/bewerbung/lebenslauf.md) when shaping CV sections, layout expectations, and ATS-safe wording.
- Use [todo.md](d:/bewerbung/todo.md) when shaping cover-letter structure, tone, and employer-specific argumentation.
